## 038A-1 — Fix `npm run dev`: kill de árbol de procesos en Windows + limpieza de huérfanos

- **Qué:** `npm run dev` fallaba siempre ("Acceso denegado (os error 5)") y la poda de targets no liberaba espacio (20.3 GB > límite 15 GB) por procesos huérfanos de una instancia dev previa: `cargo` (PID 18624) y `glory-backend.exe` (PID 16120) seguían vivos; `child.kill()` de Node en Windows solo mata al hijo directo y deja huérfanos los nietos (cargo → glory-backend). El huérfano de cargo hacía que `clean-cargo-target.ps1` detectara "build activo" y saltara TODAS las fases de limpieza. Se corrigió `glory-rs/scripts/dev.mjs` con 3 cambios:

  - `cleanup()`: al cerrar dev, mata árboles (antes `child.kill()`).
  - `killStaleProjectProcesses(cargoTargetDir, binName)`: al arrancar, mata binarios huérfanos de instancias previas SOLO si no hay un marcador vivo `.glory-cargo-active-*.json` (protege instancias legítimas).

- **Gotchas:**
